# 网络综合实验配置

## 接口对应关系

| 设备 | 接口        | 连接 |
| ---- | ----------- | ---- |
| RT1  | GE0/0/0     | PC1  |
| RT1  | GE0/0/1     | PC2  |
| RT1  | Serial4/0/0 | RT2  |
| RT2  | Serial4/0/0 | RT1  |
| RT2  | GE0/0/0     | PC3  |
| RT2  | Serial4/0/1 | RT3  |
| RT3  | Serial4/0/0 | RT2  |
| RT3  | GE0/0/0     | PC4  |

## IPv6地址规划

| 网段      | 用途                 | 地址                       |
| --------- | -------------------- | -------------------------- |
| 2001::/64 | RT1 - PC1            | RT1: 2001::1, PC1: 2001::2 |
| 2002::/64 | RT1 - PC2            | RT1: 2002::1, PC2: 2002::2 |
| 2003::/64 | RT1 - RT2 (PPP PAP)  | RT1: 2003::1, RT2: 2003::2 |
| 2004::/64 | RT2 - PC3            | RT2: 2004::1, PC3: 2004::2 |
| 2005::/64 | RT2 - RT3 (PPP CHAP) | RT2: 2005::1, RT3: 2005::2 |
| 2006::/64 | RT3 - PC4            | RT3: 2006::1, PC4: 2006::2 |

## RT1 完整配置

```
sys
sysname RT1
ipv6

int GigabitEthernet 0/0/0
ipv6 enable
ipv6 address 2001::1/64
quit

int GigabitEthernet 0/0/1
ipv6 enable
ipv6 address 2002::1/64
quit

int Serial 4/0/0
link-protocol ppp
ppp authentication-mode pap
ppp pap local-user rt1 password cipher huawei123
ipv6 enable
ipv6 address 2003::1/64
quit

ripng 1
quit

int GigabitEthernet 0/0/0
ripng 1 enable
quit

int GigabitEthernet 0/0/1
ripng 1 enable
quit

int Serial 4/0/0
ripng 1 enable
quit

save
```

## 验证测试

```
# 查看IPv6路由表
display ipv6 routing-table

# 查看RIPng信息
display ripng 1

# 查看OSPFv3邻居
display ospfv3 peer

# 查看PPP状态
display interface Serial 4/0/0

# PC1 ping PC4（应该通）
ping ipv6 2006::2
```

## 注意事项

1. **Serial接口**：在eNSP中路由器默认没有Serial接口，需要在设备上添加Serial接口卡
2. **PPP认证**：PAP是明文认证，CHAP是加密认证，两边配置要匹配
3. **路由重分布**：RT2作为边界路由器，必须做RIPng和OSPFv3的双向重分布才能实现全网互通
4. **密码格式**：新版eNSP使用 `password cipher` 代替 `password simple`
