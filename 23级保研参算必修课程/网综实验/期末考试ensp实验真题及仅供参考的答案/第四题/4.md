# 网络综合实验配置

## 接口对应关系

| 设备 | 接口        | 连接 |
| ---- | ----------- | ---- |
| RT1  | GE0/0/0     | PC1  |
| RT1  | GE0/0/1     | PC2  |
| RT1  | Serial4/0/0 | RT2  |
| RT2  | Serial4/0/0 | RT1  |
| RT2  | GE0/0/0     | PC3  |
| RT2  | Serial4/0/1 | RT3  |
| RT3  | Serial4/0/0 | RT2  |
| RT3  | GE0/0/0     | PC4  |

## IPv6地址规划

| 网段      | 用途                 | 地址                       |
| --------- | -------------------- | -------------------------- |
| 2001::/64 | RT1 - PC1            | RT1: 2001::1, PC1: 2001::2 |
| 2002::/64 | RT1 - PC2            | RT1: 2002::1, PC2: 2002::2 |
| 2003::/64 | RT1 - RT2 (PPP CHAP) | RT1: 2003::1, RT2: 2003::2 |
| 2004::/64 | RT2 - PC3            | RT2: 2004::1, PC3: 2004::2 |
| 2005::/64 | RT2 - RT3 (HDLC RIP) | RT2: 2005::1, RT3: 2005::2 |
| 2006::/64 | RT3 - PC4            | RT3: 2006::1, PC4: 2006::2 |

```
sys

ospfv3 1
router-id 1.1.1.1
quit

int GigabitEthernet 0/0/0
ospfv3 1 area 0
quit

int GigabitEthernet 0/0/1
ospfv3 1 area 0
quit

int Serial 4/0/0
ospfv3 1 area 0
quit

save
```

## 配置关键点说明

1. **RT1和RT2连接**：
   - 使用PPP链路层协议
   - CHAP认证方式（对比题目图中的PPP CHAP）
   - RT1为认证客户端，RT2为认证服务器
   - 两端都运行OSPFv3在Area0
2. **RT2和RT3连接**：
   - 使用HDLC链路层协议（题目图中标注为HDLC协议）
   - 运行RIPng协议
   - 无需认证配置
3. **RT2双向路由重分布**：
   - OSPFv3导入RIPng路由：`import-route ripng 1`
   - RIPng导入OSPFv3路由：`import-route ospfv3 1`
   - 确保两个域内的路由能互相学习
4. **地址规划简化**：
   - 使用2000::-2005::简短网段
   - 所有PC地址为x2（.2），所有路由器为x1（.1）
   - 符合题目要求的简洁地址规划
5. **注意事项**：
   - Serial接口在eNSP需要手动添加
   - CHAP认证时，RT1的本地用户名必须是rt1，RT2的AAA中要添加rt1
   - HDLC是默认的Serial链路层协议，可不指定也可显式指定
   - 所有IPv6地址都使用/64前缀长度
