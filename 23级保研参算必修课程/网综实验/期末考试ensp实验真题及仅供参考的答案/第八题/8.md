# 网络综合实验配置（静态路由 + OSPFv3）

## 拓扑说明

```
PC1(VLAN1) ---+
              |--- L3SW1 ===静态路由=== L3SW2 ===OSPFv3=== RT1 --- PC4
PC2(VLAN2) ---+      (VLAN5)       |       (VLAN4)
                               PC3(VLAN3)
```

- L3SW1 和 L3SW2 之间：**静态路由**
- L3SW2 和 RT1 之间：**OSPFv3 Area 0**
- ACL：阻止PC3与RT1之间的所有通信

## 接口对应关系

| 设备  | 接口   | 连接  |
| ----- | ------ | ----- |
| L3SW1 | G0/0/1 | PC1   |
| L3SW1 | G0/0/2 | PC2   |
| L3SW1 | G0/0/3 | L3SW2 |
| L3SW2 | G0/0/1 | PC3   |
| L3SW2 | G0/0/2 | L3SW1 |
| L3SW2 | G0/0/3 | RT1   |
| RT1   | G0/0/0 | L3SW2 |
| RT1   | G0/0/1 | PC4   |

## IPv6地址规划

| 网段      | 用途                | 地址                           |
| --------- | ------------------- | ------------------------------ |
| 2000::/64 | VLAN1 (PC1)         | L3SW1: 2000::1, PC1: 2000::2   |
| 2001::/64 | VLAN2 (PC2)         | L3SW1: 2001::1, PC2: 2001::2   |
| 2002::/64 | VLAN3 (PC3)         | L3SW2: 2002::1, PC3: 2002::2   |
| 2003::/64 | VLAN4 (L3SW2-RT1)   | L3SW2: 2003::1, RT1: 2003::2   |
| 2004::/64 | VLAN5 (L3SW1-L3SW2) | L3SW1: 2004::1, L3SW2: 2004::2 |
| 2005::/64 | RT1-PC4             | RT1: 2005::1, PC4: 2005::2     |

## L3SW1 完整配置（使用静态路由）

```
sys
sysname L3SW1
ipv6
vlan batch 1 2 5

int g0/0/1
port link-type access
port default vlan 1
quit

int g0/0/2
port link-type access
port default vlan 2
quit

int g0/0/3
port link-type trunk
port trunk allow-pass vlan 5
quit

int vlanif 1
ipv6 enable
ipv6 address 2000::1/64
quit

int vlanif 2
ipv6 enable
ipv6 address 2001::1/64
quit

int vlanif 5
ipv6 enable
ipv6 address 2004::1/64
quit

ipv6 route-static 2002:: 64 2004::2
ipv6 route-static 2003:: 64 2004::2
ipv6 route-static 2005:: 64 2004::2

save
y
```

ipv6 route-static 2001:: 64 2004::1

import-route static

## RT1 完整配置（OSPFv3 + ACL）

```
sys
sysname RT1
ipv6

int g0/0/0
ipv6 enable
ipv6 address 2003::2/64
quit

int g0/0/1
ipv6 enable
ipv6 address 2005::1/64
quit

ospfv3 1
router-id 3.3.3.3
import-route direct
quit

int g0/0/0
ospfv3 1 area 0
quit

acl ipv6 3001
rule deny ipv6 source 2002::2/128
rule permit ipv6
quit

acl ipv6 3002
rule deny ipv6 destination 2002::2/128
rule permit ipv6
quit

int g0/0/0
traffic-filter inbound ipv6 acl 3001
traffic-filter outbound ipv6 acl 3002
quit

save
y
```

## 补充说明

### 路由协议分工

- **静态路由**：L3SW1和L3SW2之间手动配置静态路由
- **OSPFv3**：负责L3SW2和RT1之间的路由交换（Area 0）
- **L3SW2**：在OSPFv3中引入静态路由和直连路由，使RT1能学到所有网段

### ACL说明

- ACL 3001（入方向）：阻止来自PC3(2002::2)的流量进入RT1
- ACL 3002（出方向）：阻止发往PC3(2002::2)的流量从RT1发出
- 双向阻止确保PC3与RT1之间完全无法通信

## 如果要求PC3能访问PC4，只是不能访问RT1接口

需要修改RT1的ACL，只阻止PC3访问RT1的两个接口地址：

```
sys
undo acl ipv6 3001
undo acl ipv6 3002

acl ipv6 3001
rule deny ipv6 source 2002::2/128 destination 2003::2/128
rule deny ipv6 source 2002::2/128 destination 2005::1/128
rule permit ipv6
quit

acl ipv6 3002
rule deny ipv6 source 2003::2/128 destination 2002::2/128
rule deny ipv6 source 2005::1/128 destination 2002::2/128
rule permit ipv6
quit

int g0/0/0
traffic-filter inbound ipv6 acl 3001
traffic-filter outbound ipv6 acl 3002
quit

save
y
```
