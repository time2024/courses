# 网络综合实验配置 

## 接口对应关系

| 设备  | 接口   | 连接  |
| ----- | ------ | ----- |
| L3SW1 | G0/0/1 | PC1   |
| L3SW1 | G0/0/2 | PC2   |
| L3SW1 | G0/0/3 | L3SW2 |
| L3SW2 | G0/0/1 | PC3   |
| L3SW2 | G0/0/2 | L3SW1 |
| L3SW2 | G0/0/3 | RT1   |
| RT1   | G0/0/0 | L3SW2 |
| RT1   | G0/0/1 | PC4   |

## IPv6地址规划

| 网段      | 用途                | 地址                           |
| --------- | ------------------- | ------------------------------ |
| 2000::/64 | VLAN1 (PC1)         | L3SW1: 2000::1, PC1: 2000::2   |
| 2001::/64 | VLAN2 (PC2)         | L3SW1: 2001::1, PC2: 2001::2   |
| 2002::/64 | VLAN3 (PC3)         | L3SW2: 2002::1, PC3: 2002::2   |
| 2003::/64 | VLAN4 (L3SW2-RT1)   | L3SW2: 2003::1, RT1: 2003::2   |
| 2004::/64 | VLAN5 (L3SW1-L3SW2) | L3SW1: 2004::1, L3SW2: 2004::2 |
| 2005::/64 | RT1-PC4             | RT1: 2005::1, PC4: 2005::2     |

## L3SW1 完整配置

```
sys
sysname L3SW1
ipv6
vlan batch 1 2 5

int g0/0/1
port link-type access
port default vlan 1
quit

int g0/0/2
port link-type access
port default vlan 2
quit

int g0/0/3
port link-type trunk
port trunk allow-pass vlan 5
quit

int vlanif 1
ipv6 enable
ipv6 address 2000::1/64
quit

int vlanif 2
ipv6 enable
ipv6 address 2001::1/64
quit

int vlanif 5
ipv6 enable
ipv6 address 2004::1/64
quit

ripng 1
quit

int vlanif 1
ripng 1 enable
quit

int vlanif 2
ripng 1 enable
quit

int vlanif 5
ripng 1 enable
quit

save
```

## RT1 完整配置

```
sys
sysname RT1
ipv6

int g0/0/0
ipv6 enable
ipv6 address 2003::2/64
quit

int g0/0/1
ipv6 enable
ipv6 address 2005::1/64
quit

ipv6 route-static 2000:: 64 2003::1
ipv6 route-static 2001:: 64 2003::1
ipv6 route-static 2002:: 64 2003::1
ipv6 route-static 2004:: 64 2003::1

acl ipv6 3001
rule deny ipv6 source 2002::2/128
rule permit ipv6
quit

acl ipv6 3002
rule deny ipv6 destination 2002::2/128
rule permit ipv6
quit

int g0/0/0
traffic-filter inbound ipv6 acl 3001
traffic-filter outbound ipv6 acl 3002
quit

save
```

## 验证测试

```
# 查看L3SW1路由表，确认有2005::/64
display ipv6 routing-table

# 查看RIPng信息
display ripng 1

# PC1 ping PC4（应该通）
ping ipv6 2005::2

# PC3 ping RT1（应该不通）
ping ipv6 2003::2
```

## 如果要求PC3能访问PC4，只是不能访问RT1接口

需要修改RT1的ACL，只阻止PC3访问RT1的两个接口地址：

```
sys
undo acl ipv6 3001
undo acl ipv6 3002

acl ipv6 3001
rule deny ipv6 source 2002::2/128 destination 2003::2/128
rule deny ipv6 source 2002::2/128 destination 2005::1/128
rule permit ipv6
quit

acl ipv6 3002
rule deny ipv6 source 2003::2/128 destination 2002::2/128
rule deny ipv6 source 2005::1/128 destination 2002::2/128
rule permit ipv6
quit

int g0/0/0
traffic-filter inbound ipv6 acl 3001
traffic-filter outbound ipv6 acl 3002
quit

save
```

### 正确的修改ACL方法（供参考）

如果以后需要修改已应用的ACL，正确顺序是：

```
int g0/0/0
undo traffic-filter inbound ipv6 acl 3001
undo traffic-filter outbound ipv6 acl 3002
quit

undo acl ipv6 3001
undo acl ipv6 3002

# 然后再创建新ACL并应用
```
